# Logo design

Original device-themed logo generated with the built-in imagegen tool.
PNG preserves generated transparency; ICO only converts the same design to Windows icon sizes.
No logo or security badge from another vendor is used.

## Final prompt

Create a unique app icon for Allzip, a free file compression utility. Device theme: a compact portable external storage drive shaped like a softly rounded upright cartridge, with a bold vertical zipper closing its center and a small file-folder tab peeking out. Distinctive palette: warm amber, orange, graphite and cream, clearly different from blue and teal tools. Refined simple geometric product logo, clean flat shapes with restrained soft depth, strong recognizable silhouette at 32px, balanced square composition with generous safe margins. No text, no letters, no badges, no shields, no lock, no watermark, no operating-system brand marks. Actual transparent background around centered icon. Original professional desktop application icon, not a mockup or icon sheet.
